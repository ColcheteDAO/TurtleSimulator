CC: Tweaked Lua API Reference (Supported in Simulator)

Movement & Rotation

turtle.forward() / turtle.back() / turtle.up() / turtle.down() → boolean, string|nil

turtle.turnLeft() / turtle.turnRight() → boolean

Digging & Placing

turtle.dig() / turtle.digUp() / turtle.digDown() → boolean, string|nil (mines block & collects drop in inventory)

turtle.place() / turtle.placeUp() / turtle.placeDown() → boolean, string|nil (places block from selected slot)

Block Inspection & Detection

turtle.detect() / turtle.detectUp() / turtle.detectDown() → boolean (true if solid block)

turtle.inspect() / turtle.inspectUp() / turtle.inspectDown() → boolean, table { name = "minecraft:...", tags = {...} }

turtle.compare() / turtle.compareUp() / turtle.compareDown() → boolean

Inventory & Fuel System (16 Slots)

turtle.select(slotNum) → boolean (1 to 16)

turtle.getSelectedSlot() → number

turtle.getItemCount([slot]) / turtle.getItemSpace([slot]) → number

turtle.getItemDetail([slot]) → table { name = "minecraft:...", count = n } | nil

turtle.transferTo(slot, [count]) → boolean

turtle.refuel([count]) → boolean, string|nil (consumes coal, planks, logs, sapling)

turtle.getFuelLevel() / turtle.getFuelLimit() → number

turtle.drop([count]) / turtle.dropUp([count]) / turtle.dropDown([count]) / turtle.suck([count]) → boolean

CraftOS Globals

print(...) / write(...) / sleep(seconds) / os.sleep(seconds) / term.clear() / gps.locate() → x, y, z
